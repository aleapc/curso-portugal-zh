Queria 加上那样东西，se faz favor

Queria 是一个用来完成礼貌任务的过去时——就像英语用「I would like」代替「I want」的那个小把戏。你从不需要改动它，因为你只为你自己说话。它两边都被垫上了缓冲：前面是招呼，后面是 se faz favor 或 por favor，你唯一要选的就是中间那个名词，而它已经把自己的冠词带着一起来了。

Queria um café, se faz favor. — 我想要一杯咖啡，谢谢。
Queria uma imperial, se faz favor. — 我想要一杯小生啤，谢谢。

礼貌就藏在你没有说出口的那个代词里

这些句子里都没有「你」，这不是偷懒——这就是礼貌的形式。这里的葡萄牙语用没有主语的第三人称动词来搭出尊敬：tem、pode、queria。要在那个位置放一个代词，就等于你必须对面前那个人做一个决定，而最稳妥的一句话正是永远不需要做那个决定的那句。Vocês（复数「你们」）是另一回事，完全平常；要避开的，是单数的那个「你」。

Por favor 还是 se faz favor

两者都正确，都被不停地用。Por favor 是一种固定用法，这大概就是有些人形容它更中性、更不带人情色彩的原因；而 se faz favor 的变体被形容为同时标示更多的礼貌和更多的距离。「其中一个明确比另一个更正式」这个想法所依赖的意见，来源自己都称之为「并非有共识」。挑你嘴里更顺的那个，别再想它了——没人在给这个打分。

那只不请自来的篮子

面包、黄油、橄榄，有时还有一小块奶酪：那就是 couvert，它在价目表上是有名字的一项，旁边写着价格。要紧的规则是：凡是顾客没有要求的，都不得收费。实际操作里，那只盘子作为一种「提议」落在你面前，所以决定应该放在这一餐的开头，而不是结尾：não, obrigado——如果你是女性，就说 obrigada——pode levar, se faz favor。你吃了就欠了，这很公平——「消费」正是关键差别。不公平、也不欠的，是为你原封退回的一盘东西付钱。

Obrigado，以及那个和你本人一致的词

男性说 obrigado，女性说 obrigada，它绝不因你所感谢的对象而改变。这不寻常，也是一份礼物：你只学一次自己的那个形式，然后一辈子每天用上十次，在开口的那一刻不需要做任何决定。
